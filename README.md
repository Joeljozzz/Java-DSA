# Java DSA Programs

This repository contains a collection of simple **Java programs** that cover the basics of programming and introductory Data Structures & Algorithms (DSA) concepts.  
Each file demonstrates core logic such as loops, conditionals, number manipulation, and basic mathematical algorithms.

---

## 📂 Files Included

| File | Description |
|------|--------------|
| `FirstProgram.java` | Basic Java program setup and syntax demonstration |
| `Comparision.java` | Demonstrates use of comparison operators |
| `loops.java` | Examples of different loop constructs in Java |
| `Primecheck.java` | Checks whether a given number is prime |
| `FirstNFibonachi.java` | Prints the first N Fibonacci numbers |
| `DigitsOfNumber.java` | Extracts and prints each digit of a number |
| `NofDigits.java` | Counts the total number of digits in a given number |
| `reverseofNum.java` | Reverses the digits of a number |
| `inverseofnum.java` | Finds the inverse of a number based on digit positions |
| `Printz.java` | Simple printing logic (pattern or character output) |
| `ScanningIssues.java` | Demonstrates correct handling of user input using Scanner |

---

## 🧠 Purpose

These programs are intended for:
- Practicing **basic Java syntax and input/output**
- Understanding **loops, conditionals, and arithmetic logic**
- Building a foundation for **Data Structures and Algorithms (DSA)** concepts
